SIKE! I ended up just not doing anything for the rest of the day lol. Its now the next day (I would say morning but I've already done all the work and I'm writing this at like midnight) and I've spent most of the day writing the firmware. I'm happy to say that it is done!

It took a bunch of stiching together of a bunch of sources and a lot of reading docs but it is done :) 
Heres a general overview of what goes on:

Every loop, we:
Wait for data to transfer from the adc via dma
Copy the data into a working buffer, scaling to the correct range
Read the control inputs and update values accordingly
Restart the dma capture
Process the working buffer
Copy the working buffer to the output, writing via pwm (this step is iffy and I'd really like to test it in person lol)

I stole a bunch of the reverb algorithm and code from [an open source implementation on github](https://github.com/SergeiGorskiy/IFMO_Reverb/tree/master/Freeverb_original), but it was spread out as a bunch of cpp, so I had to flatten it and rewrite everything to just use a bunch of big buffers. Speaking of, it should only use ~65kB of memory for the main allpass and comb buffers, and the rp2040 has 256kB of ram. Pretty comfortable margin which might mean I'm able to overclock past 48kHz.
